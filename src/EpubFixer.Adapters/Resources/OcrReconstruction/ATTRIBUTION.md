# Clean Turkish lexicon

`tr_50k.txt` is the Turkish 50,000-word frequency list from
https://github.com/hermitdave/FrequencyWords, pinned to commit
`525f9b560de45753a5ea01069454e72e9aa541c6`.

The processed content is redistributed under CC BY-SA 4.0. The repository
code is MIT licensed. Entries are normalized and filtered through TRmorph at
load time before being exposed as `CleanTurkishLexicon`.
